A Power BI dashboard project analyzing hospital admissions, patient flow, resource load, and recovery metrics using real-world healthcare KPIs. Visualizes trends, readmission rates, and operational performance to support data-driven decisions in hospital management.

🏥 Hospital Performance & Recovery Metrics Dashboard

This Power BI project provides a comprehensive overview of hospital operations, focusing on admissions, patient outcomes, resource utilization, and recovery insights.

📊 Dashboard Features

- KPI Cards
  - Total Admissions
  - Average Length of Stay
  - Readmission Rate
  - Recovery Rate

- Trends & Distributions
  - Line Chart: Admissions Over Time
  - Bar Chart: Admissions by Department
  - Donut Chart: Patient Outcomes
  - Heatmap: Admissions by Day of Week and Hour

- Patient Segmentation
  - By Age Group
  - By Gender
  - By Department

- Resource Load
  - Avg. Length of Stay by Department
  - Doctor-wise Patient Load

- Filters/Slicers
  - Date Range
  - Department
  - Outcome
  - Age Group

🛠️ Tools Used
- Power BI Desktop
- DAX for calculated columns and measures
- Data Cleaning in Power Query

 📁 Dataset Structure
The dataset includes fields such as:
- `PatientID`
- `AdmissionDateTime`
- `Department`
- `LengthOfStay`
- `Outcome` (Recovered, Referred, Deceased, etc.)
- `Gender`
- `Age`
- `Doctor`

*(A cleaned sample dataset is included in this repo for demo purposes.)*

 ✅ Insights Enabled
- Identify departments with high readmission or recovery rates
- Analyze peak admission times for staffing decisions
- Understand patient flow by demographic
- Optimize hospital resource allocation
